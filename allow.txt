# Functions outside the module that make no heap allocation, as SSA names
# them. A line ending in ".*" covers every function whose name starts with
# what comes before the "*". Add a function only after reading its source:
# one that returns a new slice, grows a caller's slice, or boxes a value
# into an interface does not belong here.
#
# A line "append: <function>" names one that appends to its first argument
# and returns it, allocating only to grow it, as the builtin append does. Like
# append, it is allowed when that slice is reused memory, and reported as a
# call otherwise. It takes precedence over a ".*" line that covers it.
