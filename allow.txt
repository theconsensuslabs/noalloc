# Functions that noalloc takes to allocate nothing although their code, read
# from source or compiled, does not show it: each line is "kind: function",
# the function as SSA names it or a pattern ending in "*", and the kind says
# why.
#
#   amortized  it allocates only to grow memory the runtime keeps and reuses,
#              a cost that falls away as a program runs.
#   measured   its code cannot be followed, and a case in allow_test.go that
#              calls it counts no allocation.
#   debug      it allocates only on a path that runs to debug.
#   profiling  it allocates only on a path that runs to profile.
#
# What every other function allocates is worked out from its code, and a
# check reports each line here that it never relied on.

# A lock or a wait group that blocks keeps its waiter in a sudog from a cache
# the runtime grows when it runs dry, and wakes the next waiter through the
# scheduler.
amortized: (*sync.Mutex).*
amortized: (*sync.RWMutex).*
amortized: (*sync.WaitGroup).*

# Hashing a comparable value calls the hash function the compiler writes for
# its type, through a pointer.
measured: hash/maphash.Comparable
